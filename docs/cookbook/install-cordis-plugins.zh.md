# 安装与卸载 DSH 插件

[English](install-cordis-plugins.md) | 中文

从目录选择一个独立 Bundle。当前包统一使用 `@missher/dsh-xxx` 命名，各自保存设置。

<a id="desktop"></a>

## 桌面端

通过**插件 → 添加插件**填写所选仓库或构建后的 `.tgz` 地址。包根目录声明 `dsh.bundle.patch` 并包含运行入口；安装后检查版本和启用组件。宿主仓库本身不是插件包。

目录安装会保留对目录的链接，必须保留其文件；tarball 则保存固定快照。替换已装版本前保留旧包，等待在途任务结束。若要求重启，完全退出后再打开 DSH。

桌面应用拥有保留的 `desktop` profile，公开 CLI 命令不能修改它。日常桌面安装使用应用自己的插件管理。

## 验证与卸载

打开插件目录列出的功能并检查加载组件；下载不等于启用。通过同一插件管理入口卸载目标包，保留其他插件、凭据和会话。

当前包不设置宿主版本范围；开发 SDK 是实测基线，实际所需接口仍须存在。官方版本号更新本身不代表插件已经兼容。

Media 保持私有，访问需要仓库权限。MSE 仅发布独立学习产品；Git 克隆不包含凭据或个人学习记录。

CLI 或 Web profile 的安装遵循所选包 README，并使用独立测试数据目录。原生桌面点击与真实模型调用分别验收。
