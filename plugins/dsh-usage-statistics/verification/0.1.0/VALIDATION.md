原生合成会话包含 30,000 Token、76% 缓存命中率和 90 秒已完成轮次。模型及推理强度的请求头未放入该合成日志，因此截图中相应两项显示「—」。界面没有填写 API Key，没有发起真实模型请求；这些数字不是用户账户或日常会话的用量。

验证发现并修复了独立 Client Remote 必须通过 `ctx.inject(['remote.usageStatistics'], ...)` 获取已声明作用域的问题。独立服务、Locale、缓存和 CSS 都随插件生命周期管理。验收夹具单独声明 package scope，避免被 Client 模块发现误认为插件的第二入口。

原生测试时，开始检查所用的 `/Applications/DeepSeek Harness.app` 已不在原位置，源码目录下的展开应用副本也已缺失，因此改用只读挂载的已存在 0.5.10 DMG。没有覆盖或恢复日常应用，也没有安装到日常 `~/.dsh`。

机器可读报告在源码的 `verification/`；原生截图在 `output/playwright/`。最终安装包的 SHA-256 见 `dist/SHA256SUMS`。最终包的三个运行时入口与原生验收使用的入口逐字节一致；打包文档和许可证的后续整理不改变运行时代码。

未验收 Windows / Linux 原生 UI、后续官方 alpha 宿主、其他统计插件共存或用户真实历史库。插件功能本身不需要真实模型调用。大规模历史库的首次刷新性能未实测；默认采用上游的 12 秒刷新预算与部分结果提示。
