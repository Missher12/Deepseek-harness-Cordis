# 使用统计插件

本目录是独立 Harness Bundle。主责当前 Harness 数据目录的跨会话用量、活动、常用模型/推理强度及工具/技能排行，只维护本插件的统计设置页、数据传输和安装验证，不是通用 UI 项目。保留其他项目与日常数据。当前兼容版本与验证层级以 README.md、VALIDATION.md 为准。

context-manager 的当前会话累计用量、上下文占用、内容截面和详情展开不归本插件；模型支持的思考档位配置也不归本插件。统计只观察已记录的模型与推理强度，不写能力声明或设置。两个插件不建立相互运行依赖；context-manager 的官方峰谷提示是用户已授权的职责例外，不能搬入本插件。

统计源为宿主会话持久化服务；不可绕过它扫描私有日志格式。插件只写独立派生缓存。所有注册须随 Cordis 生命周期撤销；0.1.7-rc.2 没有内置统计页，卸载应撤销插件页面和服务。不得调用模型、修改模型设置、写入会话或凭据来制造统计。

改动后按影响运行类型检查、相关测试、构建和隔离 profile 验证。可安装产物包含完整 Host/Client/Typert 入口。保留来源与许可证，实际宿主验收不能用静态截图或 mock 代替。

2026-09-28 协调阶段仅做职责审查、文档纠偏和相关回归。构建及有写入行为的测试必须使用隔离副本；不重建可能被日常插件链接的原目录 lib，不改生产 profile，不重启应用，不覆盖已交付安装包。REQ-02、REQ-03 不在此实现。本轮不暂存、提交、推送或发布；只写本项目说明及协调目录的 ui-usage.md 独占回执，不修改总台账或其他插件。
