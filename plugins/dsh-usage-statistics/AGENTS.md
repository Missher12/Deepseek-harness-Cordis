# 使用统计插件

本目录是独立 Harness Bundle，当前维护入口是统一仓库的 `plugins/dsh-usage-statistics`。主责当前 Harness 数据目录的跨会话用量、活动、常用模型/推理强度及工具/技能排行，只维护本插件的统计设置页、数据传输和安装验证，不是通用 UI 项目。保留其他项目与日常数据。当前兼容版本与验证层级以 README.md、VALIDATION.md 为准。

context-manager 的当前会话累计用量、上下文占用、内容截面和详情展开不归本插件；模型支持的思考档位配置也不归本插件。统计只观察已记录的模型与推理强度，不写能力声明或设置。两个插件不建立相互运行依赖；模型服务的峰谷提示不能搬入本插件。

统计源为宿主会话持久化服务；不可绕过它扫描私有日志格式。插件只写独立派生缓存。所有注册须随 Cordis 生命周期撤销，卸载应撤销插件页面和服务。不得调用模型、修改模型设置、写入会话或凭据来制造统计。

改动后按影响运行类型检查、相关测试、构建和隔离 profile 验证。可安装产物包含完整 Host/Client/Typert 入口。保留来源与许可证，实际宿主验收不能用静态截图或 mock 代替。
